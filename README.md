# SDOC AI

AI-Powered Shipping Document Reconciliation System

## Overview

SDOC AI is a cloud-based AI solution designed to assist shipping operations by classifying shipping emails, extracting information from shipping documents, and identifying discrepancies between Shipping Instructions (SI) and Bills of Lading (BL).

## Project Structure

- `backend/` — FastAPI backend and AI processing pipeline
- `frontend/` — Next.js web dashboard
- `data/` — Hackathon dataset
- `tests/` — Evaluation and testing
- `docs/` — Architecture, evaluation and documentation
- `submission/` — Competition submission files

## Technology Stack

- Python
- FastAPI
- Gemini API
- Next.js
- Google Cloud Run
- Supabase
- Docker
